### $\color{green}{\text{Example 1.}}$  
$\text{We have :}$  
$$
F(x,y)= \frac{1}{3}x^3-xy^2+\lambda_1(x^2+y^2)+\lambda_2x + \lambda_3y
$$  
- #### $\color{blue}{\text{Caustic}(\Sigma_1):}$  
    $\exists (x_0,y_0)\in \mathbb{R^2} \text{ s.t } \begin{cases}
        F_x(x_0,y_0)=0  \\
        F_y(x_0,y_0)=0  \\
        Det(Hess(H(x_0,y_0)))=0
    \end{cases}$  
    $\Rightarrow$  
    $$
    \color{red}{27\lambda_1^8-18\lambda_1^4\lambda_2^2-8\lambda_1^2\lambda_2^3-\lambda_2^4-18\lambda_1^4\lambda_3^2+24\lambda_1^2\lambda_2\lambda_3^2-2\lambda_2^2\lambda_3^2-\lambda_3^4=0} \tag{*}
    $$  
    $\text{The graph is like :}$  
    ![$D_4\text{Custic(big)}$](D4_Caustic_big.png)
    $\text{around (0,0,0) is like : }$  
    ![$D_4\text{Custic(big)}$](D4_Caustic_small.png)

- #### $\color{blue}{\text{Maxwell stratum}(\Sigma_2):}$  
    $\exist \text{ different }(x_1,y_1),(x_2,y_2) \in \mathbb{R^2} \text{ s.t }\begin{cases}
        F_x(x_1,y_1)=0  \\
        F_x(x_2,y_2)=0  \\
        F_y(x_1,y_1)=0  \\
        F_y(x_2,y_2)=0  \\
        F(x_1,y_1)=F(x_2,y_2)
    \end{cases}$  
    $\Rightarrow$  
    $$
        \color{red}{\lambda_3(\lambda_3^2-3\lambda_2^2)=0} \tag{**}
    $$  
    $\text{The graph is like :}$  
    ![$D_4\text{Maxwell}$](D4_maxwell.png)

    [INPUT] :

        ClearAll["Global`*"];

        Clear[\[Lambda]1, \[Lambda]2, \[Lambda]3, x, y]
        F = 1/3 x^3 - x y^2 + \[Lambda]1 (x^2 + y^2) + \[Lambda]2 x + \[Lambda]3 y;
        Fx = D[F, x];
        Fy = D[F, y];
        hess = {{D[Fx, x], D[Fx, y]}, {D[Fy, x], D[Fy, y]}};
        detH = Det[hess] // Simplify;
        eqns = {Fx == 0, Fy == 0, detH == 0};

        
        GroebnerBasis[eqns, {\[Lambda]1, \[Lambda]2, \[Lambda]3}, {x, y}]
    
    [OUTPUT] :

        18 \[Lambda]1^4 \[Lambda]3^2 +

- ### $\color{green}{\text{Code of (**) is :}}$  
    ```wl
    [INPUT] :

        Clear[F, Fx, Fy];

        F[x_, y_] := 1/3 x^3 - x y^2 + l1 (x^2 + y^2) + l2 x + l3 y;
        Fx[x_, y_] := Evaluate[D[F[x, y], x]];
        Fy[x_, y_] := Evaluate[D[F[x, y], y]];

        (*t makes (x1,y1) , (x2,y2) different*)
        polys = {Fx[x1, y1], Fy[x1, y1], Fx[x2, y2], Fy[x2, y2], 
        F[x1, y1] - F[x2, y2], t ((x1 - x2)^2 + (y1 - y2)^2) - 1};

        (*cancle out x1,y1,x2,y2,t，stay l1,l2,l3*)
        relations = GroebnerBasis[polys, {l1, l2, l3}, {x1, y1, x2, y2, t}];

        
        Factor /@ relations // Column

    [OUTPUT] :

        l3 (3 l2^2 - l3^2)
    
    ```
